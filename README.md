# Анимация стока — плагин для Топоматик 360

Плагин для Топоматик 360. Показывает анимацией, куда стекает вода по 3D-поверхности: тёмные линии течения, по ним бегут светлые потоки (скорость растёт с уклоном), сверху падает дождь, вода собирается в понижениях.

## Возможности

- Вид «Вода»: плотные линии течения и бегущие по ним потоки; вид «Капли с хвостами»
- Стрелки направления стока, дождь, отметки понижений (мест, где вода собирается)
- Сводка: перепад высот, средний и максимальный уклон, число понижений, доля плоских участков
- Работает по выбранной поверхности, по выделению в Инспекторе или по щелчку; несколько поверхностей объединяются
- Пауза замораживает кадр, «Пуск» продолжает; Esc останавливает
- Настройки: плотность капель, скорость, длина хвоста, размер стрелок, прозрачность, слои, вид анимации
- Чертёж и модель не изменяются

## Что нужно на входе

Триангулированная 3D-поверхность: рельеф или TIN (например, IFC-модель с `IfcTriangulatedFaceSet`), у которой в каждой точке плана одна высота. Линии, полилинии, точки и плоские 2D-чертежи не подходят. Вертикаль — ось Z. Анимация показывает направление стока по уклону, это визуализация, а не гидрологический расчёт расхода и затопления.

## Установка

1. Скачайте `ru.abr.flowanim-<версия>.apx` из раздела **Releases** этого репозитория.
2. В Топоматик 360 откройте панель **Плагины** и выберите **Установить из файла**.
3. Укажите скачанный `.apx`. На ленте появится вкладка **Сток**.

Если обновляете плагин, удалите прежнюю версию и установите новую; после смены версии плагина перезапустите приложение.

## Как пользоваться

1. Откройте модель с поверхностью и выделите её (в Инспекторе или в виде).
2. Вкладка **Сток** → **Пуск**. Если выделения нет, плагин возьмёт единственную поверхность или предложит выбрать из списка.
3. **Настройки** на ленте (группа «Сервис») открывают меню с видом анимации, слоями и числовыми параметрами. Те же настройки есть в панели «Управление стоком».
4. **Пауза** замораживает картинку, **Стоп** убирает слой.
